WORTFALL — implementation notes

Review-fix update (v2.4) — learning + robustness changes driven by a full code/design
review:
- Recall mode (default OFF per user preference — the German is visible again; `R` in
  the menu toggles it ON): when ON the German text of a falling word is hidden;
  the prompt shows only `[ _ == English == Urdu ]`. The player must produce German
  from meaning — retrieval, not transcription.
- Pronunciation now plays when a word SPAWNS (SPAWN_HOOK in game.py), linking ear + eye
  before typing; typing a word correctly is silent by design. The old solve hook was
  removed.
- Weak-word review (default ON, `W` toggles): the picker is progress-weighted —
  unseen words get `unseen_weight` (1.5), seen words `1 + missed_weight * missed/seen`
  (2.0 max bonus). Progress data finally feeds back into selection.
- Prefix-collision guard in Picker.pick: a word whose normalized key equals, is a
  prefix of, or contains an active on-screen key (e.g. `es` vs `essen`, `sie` vs `Sie`)
  is not spawned while the other is active; collision avoidance outranks recency in the
  fallback chain.
- Live dead-prefix feedback: typing a character that no falling word starts with counts
  a mistake immediately, shows `✗ <buffer> — no word starts like this`, clears the
  buffer and fires the "wrong" event. A full 40-char buffer warns instead of ignoring
  keys.
- Learn mode: `?` (or `!`) skips the falling word — reveals the answer, counts a miss,
  counts one learn turn and re-queues the entry after `learn_requeue_turns` (3)
  resolved turns (fixes the never-miss bug and dead re-queue);
  `change_speed` now applies the ratio new_scale/old_scale so clamping cannot drift
  word speeds (fixes speed clamp drift).
- Persistence: progress is saved in a `finally:` block (Ctrl+C safe), autosaved every
  `autosave_seconds` (30), and quitting mid-game still updates the high score. High
  scores only count "fair" runs via Game.recordable() (no infinite-lives TAB, no
  slowed speed, not learn mode).
- Pause redesigned: first ESC pauses; in pause ANY key resumes, `Q` saves and quits —
  no more accidental double-ESC exit. The game-over summary ignores keys for ~1s so a
  held Enter cannot skip it.
- Game clock: update() accumulates self.clock excluding pause time; the speed bonus
  uses `clock - word.spawn_clock`, so pausing no longer eats the bonus.
- Fall time scales with length: +0.3 s per character (time_per_char), so
  `Krankenschwester` gets more time than `ja`. Typing the article with a noun earns a
  1.5x article_bonus in optional mode. Matching strips punctuation ("Wie geht's?" →
  "wie gehts"), and plural prompts gloss the English as `(pl.)`.
- Vocab content: 480 entries, every entry now has an Urdu gloss, verbs use a consistent
  "to …" style (können/müssen: "to be able to"/"to have to"; leben "to live (be alive)"
  vs wohnen "to live (reside)"), 16 entries carry conjugation notes shown under the
  word in learn mode. Menu guards refuse to start a category with zero words in the
  selected article/plural mode.
- progress.json schema bump: {"version": 1, words, high_score}; loader reads version.
- locale.setlocale is called before curses initscr; display_width() moved to textnorm.py
  (curses-free) so spawning measures real column width including Urdu.
- Deferred (future work): strict-capitalization mode, accuracy-based scoring/lives
  curve, one-gloss-at-a-time option, end-of-session replay of missed words, Goethe
  A1 wordlist cross-check, per-word example sentences, full audio queue, pytest.

UI/behaviour update (v2.2):
- Cleaner UI: one-line header (WORTFALL · SCORE · hearts · LV · streak ×n), thin
  field separators, hint line, minimal typing line; the old control strip is gone
  (F2/F3 labels moved to the far right of the hint line; +/- and Tab still work).
- No sound on a correctly typed word: the solve chime was removed (v2.4 went further —
  pronunciation moved to word spawn).
- `[ German == English == Urdu ]`: German stays constant while English and Urdu
  blink on/off; since v2.5 they FLIP-FLOP out of phase — when English is lit Urdu
  is dark and vice versa, while the German stays constant (per-word phase).
- Falling order: uniform random Picker (now superseded in v2.4 by the default
  progress-weighted picker, toggleable with `W`; recent/on-screen words still excluded).
- Living background: twinkling stars, flying birds, cycling weather
  (clear → cloudy → rain → snow), all time-procedural and drawn behind words.
- SPACE resets the typing buffer; matching ignores spaces, so multi-word answers
  (e.g. `dashaus`) still work; articles are optional (typing the article earns the
  article bonus since v2.4).

Implements the supplied Design Document v2: curses-only terminal game; 30 FPS
monotonic timing; optional article mode (article required/off modes also available);
plural practice; all-active-word matching; recent-word and duplicate-gloss avoidance;
falling speed with per-word jitter; difficulty progression; scoring/streak/lives;
near-miss and missing-article feedback; category selection; 480 A1 vocabulary items;
progress persistence and weighted review; learn mode with skip and re-queue; summary
screen (with 1s input cooldown); terminal resize and small-terminal handling; Unicode
get_wch input and ASCII-safe renderer fallbacks.

Known scope note: the vocabulary is a curated starter A1 set, not a certified
Goethe/CEFR frequency list. Review translations and plural forms before classroom use.


Gameplay display update: falling prompts show the German word followed by its English translation. Players type the German form; exact answers auto-resolve as soon as the final character is entered, without pressing Enter.

Controls/UI update:
- A clearer title/menu and in-game control strip.
- `+` and `-` change the falling speed in 0.25x increments (0.25x to 3.00x).
- `I` toggles infinite lives.
- ESC pauses: any key resumes, `Q` (or ESC-ESC on menu/summary screens) saves and exits.
- Hallo and Tschüss include English and Urdu translations.

  cached
